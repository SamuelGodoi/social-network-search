# Social Network Connection Search – Increment 1
 
CSCE 2110 – Foundations of Data Structures
Team: Silvana Velazquez Vivanco and Samuel Lucena Godoi
 
## Files
- `socialNetwork.cpp` – the program (C++)
- 'main.cpp' - main execution file
- `friends.txt` – sample input (11 friendships, 11 users, 2 separate groups)
- 'friends2.txt' - sample input with more connections (31 friendships, 26 users, cycles included and disconnected users)

## Compile
```
g++ socialNetwork.cpp main.cpp -o main 
```
 
## Run
```
./main friends.txt
./main friends2.txt
```
